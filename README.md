# Zeus Marigold Altar

ROL: Eres un diseñador UX/UI y desarrollador web senior frontend con experiencia en desarrollo en páginas creativas
TAREA: Crea una landing page para hacer un altar digital para mi mascota, la cual es un conejo y se llama Zeus  CONTEXTO:
Las caracteristicas de la landing page son: -Paleta de colores tradicional: morado, naranja, flores de cempasuchil. -que sea interactiva al momento de pasar el cursor por algun detalle se agrande -petalos de cempasúchil cayendo -que inicie a enseñar la web al apretar la nariz de un conejito gris como botón. -La foto de mi conejo (yo te la voy a proporcionar). -un arco de flores de cempasuchil -Guirnalda de papel picado animada en el encabezado. -veladoras con una foto del conejo -Que el cursor sea en forma de zanahoria. De igual manera te comparto una imagen de idea de un altar para basarnos en ello
